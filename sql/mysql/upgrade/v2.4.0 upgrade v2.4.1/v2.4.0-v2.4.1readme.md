# V2.4.0 升级至 V2.4.1 升级说明文档

## 一、数据库升级

### 方案一：全新环境（强烈推荐）
适用于无历史数据或可接受重置演示数据的环境：

1. 进入 `initialization` 目录
2. 任选其一执行初始化脚本：
    - `v2.4.1初始化.sql`
    - `latest初始化.sql`

### 方案二：存量环境（谨慎使用）
适用于必须保留 V2.4.0 历史业务数据的场景。  
⚠️ **注意**：此方案可能存在数据兼容性风险，执行前请务必完整备份数据库。

进入 `upgrade` 目录，**严格按顺序**执行以下脚本：
1. 执行 `v2.4.1-update.sql`
2. 执行 `v2.4.1-update-data.sql`

## 二、项目依赖更新

1. 在项目 `lib` 目录下，执行 `install` 里面的命令，加载 jar 包。
2. 启动项目若出现 `common` 包授权加载失败，请联系相关人员重新授权。
3. JDK 使用 **JDK 17**，Maven 建议版本不低于 **3.9.9**。

## 三、升级注意事项

- 升级前建议**备份数据库、停止服务**
- 新增 jar 包为 V2.4.1 版本专属依赖，不可使用旧包替代
- 存量环境升级后，如遇演示数据异常，建议回滚并切换至全新部署方案
- 后续版本我们将持续优化存量升级路径的稳定性
