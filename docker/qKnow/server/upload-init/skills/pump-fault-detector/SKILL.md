# 泵站故障检测

## 概述

本 skill 用于帮助用户根据泵站运行数据生成标准化的《泵站故障检测报告》。它会引导用户提供必要的泵站信息和运行数据，然后基于内置规则判断是否存在异常，并给出故障类型、可能原因、严重程度和处理建议。

触发场景：
- 用户提供了泵站传感器数据，要求分析是否故障
- 用户要求生成泵站故障检测报告
- 用户描述泵站异常现象，需要排查和定位故障
- 用户输入如 "帮我检测一下这个泵站的故障"、"生成泵站故障报告"、"分析一下水泵运行数据" 等

## 核心流程

1. **识别意图**
   当用户提到以下关键词或场景时触发：
   - 泵站故障
   - 水泵异常
   - 故障检测 / 故障诊断
   - 故障报告 / 检测报告
   - 运行数据分析

2. **收集必要信息**
   每次优先问一个最关键的问题，最多一次问 2-3 个强相关问题。必须收集的信息包括：
   - 泵站名称 / 编号
   - 检测时间
   - 水泵型号（可选）
   - 运行数据：电流(A)、电压(V)、功率(kW)、流量(m³/h)、扬程(m)、转速(r/min)、振动速度(mm/s)、温度(℃)、轴承温度(℃)、进出口压力(MPa)、运行时长(h)
   - 异常现象描述（可选）

3. **执行故障判断**
   基于用户提供的数据，按 `references/fault-rules.md` 中的规则进行判断：
   - 单项指标越限
   - 多项指标组合异常
   - 与历史正常值对比
   - 给出故障等级：正常 / 注意 / 异常 / 严重

4. **生成故障检测报告**
   使用 `references/report-template.md` 的模板输出报告，报告应包含：
   - 基本信息
   - 检测数据汇总
   - 故障判断结果
   - 故障类型与可能原因
   - 处理建议
   - 后续跟踪建议

5. **输出格式**
   - 默认输出 Markdown 格式报告
   - 如用户需要，可输出为纯文本表格或结构化 JSON

## 产品边界

- 本 skill 仅做基于规则的故障辅助判断，不做实时控制系统联动
- 输出报告为建议性文档，最终处置以现场工程师判断为准
- 不提供设备维修操作指导以外的专业技术服务
- 不涉及 API、数据库、字段类型等技术实现细节

## 高频遗漏检查

输出报告前检查是否包含：
- 泵站名称和检测时间
- 所有关键运行数据及单位
- 明确的故障判断结论
- 故障等级
- 至少一项可能原因
- 至少一项处理建议
- 是否需要停机检修或继续观察
